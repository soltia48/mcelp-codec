# 用語集

音声符号化は語彙が濃く、いくつかの用語は一般的な用法より狭い意味でここでは使われ
ます。このコードベースでの用法として列挙します。

### 適応コードブック (adaptive codebook)

直近の励振を、1ピッチ周期ぶん遅延させて読んだもの。固定表ではなく、コーダ自身の
出力からサブフレームごとに作り直されるので「適応」と呼ばれます。*長期予測器*とも。
→ [pitch.md](pitch.md)

### 分析合成 (analysis by synthesis)

入力を直接測るのではなく、各候補の合成結果を作って入力に最も近いものを残すことで
コーダのパラメータを決める方式。→ [encoder-loop.md](encoder-loop.md)

### 帯域拡張 (bandwidth expansion)

予測係数 `aₖ` に `γᵏ`（`γ < 1`）を掛ける操作。フィルタの極を原点方向へ引き寄せ、
共振の位置を動かさずに幅を広げます。重み付けフィルタとポストフィルタの構成に
使われます。

### クラス (class)

16ビットの固定コードブック索引が選べる6つの構造のうちの1つ。索引がどのクラスに
属するかは、どの値域に落ちるかで決まります。
→ [fixed-codebook.md](fixed-codebook.md)

### 閉ループ (closed loop)

候補を合成して結果を測る探索。高価なので、開ループ探索が絞り込んだ短い範囲でのみ
実行されます。

### 励振 (excitation)

合成フィルタを駆動する信号——LPC モデルが予測できない成分。このコーデックでは、
スケールされた適応寄与とスケールされた固定コードブック寄与の和です。

### 固定コードブック (fixed codebook)

*励振波形*を選ぶ構造化された集合。疎なパルスパターンで、サブフレームごとに16ビット
索引で1つ選ばれます。→ [fixed-codebook.md](fixed-codebook.md)

### フォルマント (formant)

声道の共振。スペクトル包絡の峰として現れます。音声の了解度は主に最初の2〜3個に
依存します。

### フレーム／半フレーム／サブフレーム

320 / 160 / 80 標本。フレームは伝送単位、半フレームは分析単位、サブフレームは
励振単位です。→ [architecture.md](architecture.md)

### 励振波形 (innovation)

固定コードブックが励振に与える寄与——適応コードブックが供給する周期成分に対する
「新規」成分。

### ラグ (lag)

適応コードブックが過去の励振を読む遅延量（標本数）。有声音では1ピッチ周期に
等しくなります。ここでの範囲は 20〜143。

### LPC — 線形予測符号化

ある標本を先行標本の重み付き和としてモデル化すること。重みが*予測係数*で、そこ
から作るフィルタ `1/A(z)` が*合成フィルタ*です。→ [lpc.md](lpc.md)

### LSF / LSP

予測器の等価な別表現2種。LSF は*線スペクトル周波数*（ラジアンの角度）、LSP は
*線スペクトル対*（その余弦）。安定性が「昇順を保つこと」に帰着するため、生の
係数よりはるかに量子化・補間しやすくなります。

### 開ループ (open loop)

合成を伴わず信号に直接掛ける安価な探索。閉ループのピッチ探索の範囲を絞るために
使われます。

### 聴覚重み付け (perceptual weighting)

フォルマント領域を強調しなくするフィルタを通して符号化誤差を測ること。耳が聴き
取らない場所に誤差を残せるようになります。→ [weighting.md](weighting.md)

### ピッチ強調 (pitch sharpening)

励振波形を使用前に分数遅延ピッチ予測器に通し、パルスだけでは粗くなる周期性を
補強すること。デコーダ側の操作です。

### ポストフィルタ (postfilter)

スペクトルの谷を深くし、信号が弱くてマスクできない場所の量子化雑音を隠す
デコーダ側のフィルタ。→ [synthesis.md](synthesis.md)

### Q 表記

固定小数点のスケーリング。Q*n* 値は 2ⁿ で割った分数として読む整数です。
→ [fixed-point.md](fixed-point.md)

### 反射係数 (reflection coefficient)

Levinson-Durbin 再帰の副産物で、予測次数ごとに1つ。最初の2つはスペクトルの
大まかな傾きを要約しており、重み付けフィルタの形状判定はここから行われます。

### 残差 (residual)

逆フィルタ `A(z)` が短期予測器の説明できる成分をすべて取り除いた後に残るもの。
励振はコーダによるその近似です。

### 抑圧 (suppression)

残念ながら無関係な2つの意味があり、コード中に両方現れます。

- **雑音抑圧** — エンコーダのスペクトル整形前段。
  → [noise-suppression.md](noise-suppression.md)
- **フレーム抑圧** — 復号せず補償すべきフレームを示す伝送フラグ。
  → [bitstream.md](bitstream.md)

### 目標信号 (target)

探索が合わせにいく信号。聴覚重み付けされた入力から、既に符号化済みのサブフレーム
が説明する分を差し引いたもの。→ [encoder-loop.md](encoder-loop.md)

### トラック (track)

マルチパルスのクラスで、1つのパルスが占めうるサブフレーム内の位置の部分集合。
トラックを交互配置することで、少数のパルスと小さな索引でサブフレーム全体を覆え
ます。

### VAD — 音声区間検出

フレームが音声か背景かを判定すること。ここでは雑音床の更新を制御し、抑圧深度を
選びます。→ [noise-suppression.md](noise-suppression.md)
