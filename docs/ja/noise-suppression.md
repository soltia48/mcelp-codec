# エンコーダ前段

予測分析に入る前に、エンコーダは本格的なスペクトル雑音抑圧を掛けます。この
時代の CELP コーダとしては珍しく——多くは入力をそのまま受け取ります——そして
重要な点として、**以降のすべてが抑圧後の信号を分析します**。LPC 分析も、ピッチ
探索も、コードブック探索も、整形済みの音声を見ています。

前段は**半フレーム単位**、つまり160標本ずつ、フレームあたり2回動きます。

## 処理の連鎖

```
線形入力
   │
   ├─ 窓掛け ────── 256標本：履歴96 + 新規160、テーパ、プリエンファシス
   ├─ FFT ───────── 128点、129本の振幅ビンを得る
   ├─ 帯域化 ────── 20の臨界帯域に畳み込み、平均し、dB へ変換
   │
   ├─ 雑音床 ────── 2本の長期推定。片方は約2倍速く適応
   ├─ 特徴量 ────── 各床からどれだけ上にいるか（帯域ごと・全体）
   ├─ VAD ───────── その特徴量から音声/無音の整数スコア
   ├─ 重み ──────── 帯域ごとの抑圧深度（dB）
   │
   ├─ 整形 ──────── 帯域ごとの利得をスペクトルに適用
   ├─ 逆 FFT ────── 256標本の時間信号へ戻し、漏れ積分器を通す
   └─ 縫合 ──────── 連続するスパンをクロスフェードで繋ぐ
```

## 臨界帯域

129本のビンは、幅が次第に広がる20の帯域に畳み込まれます。耳の周波数分解能に
おおよそ従うもので、ピッチと第1フォルマントのある低域では狭く、耳がどのみち
積分してしまう高域では広くなります。各帯域のビンを合計し、帯域幅で割り、
デシベルに変換します。

半フレームあたり20個という記述は、時間方向に安価に追跡できるだけ小さく、かつ
選択的に抑圧できるだけ詳細です。

## 2本の雑音床

抑圧器は長期の帯域電力推定を1本ではなく**2本**保持します。適応速度が異なり、
片方がもう片方のおよそ2倍の速さです。各推定は、それ自身の音声区間判定が無音と
した フレームでのみ更新されるため、時間とともに音声ではなく背景に収束します。

2本ある理由は、1本では両方の目的を果たせないからです。速い推定は変化する雑音
環境に追従しますが、検出をすり抜けた音声に引き上げられます。遅い推定は頑健
ですが、雑音の実際の変化に遅れます。両方を走らせて各々に対してフレームを採点
することで、検出器は2つの意見を突き合わせられます。

## 音声区間検出

検出器は各床から得た記述を、3つの特徴量を閾値と比較することで小さな整数スコアに
変換します。

- 現在のスペクトルが床より全体としてどれだけ上にいるか；
- 同じことを帯域ごとに見て要約したもの；
- その帯域ごとの超過量の分散——雑音は自身の平均に対してスペクトル的に平坦だが、
  音声はそうではない。

スコアはその後カウンタとハングオーバを通ります。ハングオーバが肝心な部分です。
発話の途中の1フレームだけ静かになっても、コーダを無音モードに切り替えては
なりません。切り替わると雑音床が音声に適応してしまい、次のフレームの立ち上がりを
抑圧してしまいます。閾値とハングオーバ長そのものも、そのフレームの音量に応じて
選ばれます。

2つめのスコアは開ループの有声度も加味しており、エンコーダの残りが実際に使うのは
この2つめです。

## 抑圧深度

各帯域からどれだけ取り除くかは、そのフレームがどれだけ音声らしく見えたかで
決まります。深度プロファイルは3種類——確信のある無音で最も深く、確信のある音声で
最も浅い——これを固定の傾きで帯域方向に展開し、前フレームの深度と平滑化して
半フレーム間で利得が飛ばないようにします。

帯域ごとの利得をスペクトルに適用し、結果を逆変換します。変換するのは256標本
スパンですが半フレームで消費するのは160標本なので、連続するスパンを繋ぐ必要が
あります。完全な重畳加算ではなく、40標本の継ぎ目をクロスフェードし、残りは
各スパンをそのまま採ります。隣接スパンは窓が異なる部分でしか違わないので、
これで十分です。

## トレードオフ

分析の前に抑圧を掛けるのは意図的な選択で、代償があります。LPC 分析が見る信号
から雑音を除けばスペクトル包絡は綺麗になり、コードブック探索がヒスにビットを
費やすのを防げます。しかし抑圧のアーティファクトは焼き付いてしまい——デコーダに
は元に戻す手段がありません——検出器が判断を誤った帯域での過剰抑圧は、再構成音の
穴として現れます。控えめな深度プロファイルと重めの平滑化が、それを抑えています。
