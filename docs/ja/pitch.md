# 長期予測 — 適応コードブック

有声音は準周期的で、1ピッチ周期は直前の周期とよく似ています。長期予測器は
この性質を利用し、各サブフレームの励振の一部を、1ピッチ周期前に既に生成した
励振から組み立てます。

その「遅延させて読んだ過去の励振」こそが適応コードブックです。固定表ではなく
コーダ自身の直近の出力なので「適応」と呼ばれ、サブフレームごとに中身が作り
直されます。

## ラグ

| | |
|---|---|
| 範囲 | 20〜143 標本（8 kHz で 56 Hz〜400 Hz） |
| 分解能 | ラグ85付近まで ⅓ 標本、それ以上は整数 |
| 符号化 | 絶対8ビット、続いて相対5ビット |

分数分解能が効くのは短いラグ側です。そこでは1標本が周期に占める割合が大きい
ためです。ラグ85を超えると整数格子で既に十分細かいので、その分の符号は
より遠くまで届かせるために使われます。

各半フレームの第1サブフレームは**絶対**ラグを8ビットで送ります。第2サブフレーム
は**差分**を5ビットで送り、第1サブフレームの選択の近傍にある整数ラグ10個分を
⅓ 分解能で覆います。窓は範囲の両端をはみ出さないようクランプされます。

分数ラグは過去の励振の再標本化を要します。31タップの補間フィルタを3つの位相の
いずれかで読むことで行います——同じフィルタを、標本より前のタップには順方向、
後ろのタップには逆方向に読みます。

## 2段階の探索

サブフレームごとに124個の整数ラグすべてを完全な分析合成で試すとエンコーダの
コストを占有してしまうため、探索は分割されています。

### 開ループ（半フレームに1回）

開ループ探索は重み付け信号に直接働きます——合成はしません。信号を正規化した
うえで、ラグ範囲を狭めながら3回走査します。

```
(143 … 63)   (79 … 39)   (39 … 19)
```

各走査では、相関を自身が取られた区間の電力で正規化し、最大となるラグを残します。
最長候補に有利なバイアスが掛かっており、短いラグは明確に優れていない限り
最長候補を押しのけられません。これは**ピッチの半分化**に対する定石の防御です
——真の周期の2倍もほぼ同じくらい相関するため、半分化したラグを選ぶと励振が
ブザー音になります。

### 閉ループ（サブフレームに1回）

開ループの推定値は探索範囲を絞るだけです。閉ループはその周辺のラグを短く並べて
——7個、有効範囲にクランプ——それぞれについて実際にフィルタ済みの寄与を作り、
目標のどれだけを説明できるかを測ります。最良の整数ラグが決まったら、その周辺の
分数位相を同じ方法で試します。

判定基準は一貫して `相関² / 電力` で、候補同士は交差乗算で比較するため除算は
不要です。

## 利得と、それを制限する理由

適応寄与にはピッチ利得が掛かり、固定コードブック利得と一緒に量子化されます
（[gain.md](gain.md) 参照）。量子化の前にエンコーダはこれをクランプします。
周期的なサブフレームでもおよそ 0.95 を超える利得は許されません。

理由は別種の安定性です。長期予測器はコーダ自身の出力を通るフィードバックループ
です。利得が1以上になるとループが鳴き、デコーダも同じループを回すため、その
鳴きは再構成音に残って成長します。利得を抑えることは強い有声フレームで予測
精度をわずかに犠牲にする代わりに、無条件の安定性を買っています。

## 周期的延長

ラグがサブフレームより短い場合、コードブックベクトルは履歴の末尾を越えます
——書き込もうとしている位置の1周期前の励振が、まだ存在しないのです。足りない
末尾は、いま生成したばかりの部分を繰り返して埋めます。ラグの小数部に応じて
8タップの補間器で再標本化します。この延長は自己参照的です。1周期分を超えて
生成すると、補間器の窓は同じループが書き込んだ標本に届きます。
