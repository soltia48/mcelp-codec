# デコーダ

## 合成

サブフレームの励振が組み上がれば、再構成はフィルタ1本です。

```
speech[n] = excitation[n] − Σ aₖ · speech[n−k]      k = 1 … 10
```

`1/A(z)` を80標本ずつ走らせ、サブフレーム間で10標本の記憶を持ち越します。
予測器が Q12、信号が Q15 なので、累算した予測値は加算前に両者の形式を揃える
ためのシフトを受けます。

再構成はこれで全部です。デコーダの他の仕事は、励振を組み立てること
（[pitch.md](pitch.md)、[fixed-codebook.md](fixed-codebook.md)、
[gain.md](gain.md) を参照）か、事後の後始末です。

## ポストフィルタ

3.6 kbit/s では再構成音の量子化雑音が聴こえます。特にフォルマント間の谷、
つまり信号自体が弱い部分で顕著です。ポストフィルタはその雑音を除去しません。
**隠します**。耳が信号を惜しまない場所で谷をさらに深くし、そこで雑音が聴こえ
なくなるようにするのです。

サブフレームごとの処理連鎖：

1. **2本の重み付けフィルタ。** そのサブフレームの LSF を固定のバイアスベクトル
   に向かって2つの異なる度合いで引き寄せ、分子 `A(z/g₂)` と分母 `A(z/g₁)` を
   得ます。LPC 係数をスケールするのではなく LSF 領域で導出するので、双方とも
   安定が保たれます。
2. **残差。** 合成音声を `A(z/g₂)` に通します。
3. **長期ポストフィルタ。** その残差に適用（後述）。
4. **再合成。** `1/A(z/g₁)` を通して戻します。
5. **利得正規化。** 短期ポストフィルタがレベルを変えてしまわないように。
6. **傾き補償。** フォルマント強調が生む低域寄りの傾きを打ち消す1次フィルタ。
   増幅にならないよう利得が選ばれます。
7. **電力整合。** 平滑化された自動利得制御を通して、フィルタ前の音声と電力を
   合わせます。ポストフィルタがレベル変化として聴こえないようにするためです。

### 長期ポストフィルタ

周期性を補強する部分です。残差に対して：

1. 探索が十分な精度を持てるよう、残差履歴を再スケールする；
2. 伝送されたピッチラグを ±1 標本、続いて両方向7つの分数位相で精密化する。
   常に `相関² / 電力` を最大化する；
3. 遅延信号をより長い16タップの分数フィルタでもう一度作り、相関の良い方を残す；
4. 勝った相関から導いた利得で遅延信号を残差に混合する。遅延信号の電力が残差との
   相関を上回らない限り、原信号に3分の2の重みを置く。

決定したラグは記憶されます。これがデコーダの有声フラグであり、次の半フレームの
励振組み立てと消失補償の経路が参照します。

## 消失補償

抑圧フラグが立ったフレームは使えるパラメータを持ちません。そのときデコーダは：

- **スペクトルを保持する。** LSF 予測器の記憶を、受信残差からではなく最後の
  正常フレームから再構築する；
- **ラグを保持する。** 最後の正常フレームから引き継いだ補償用ラグを使う；
- **利得を減衰させる。** 消失が続くほど減衰を深くする；
- **両方ではなく片方の寄与を選ぶ。** 長期ポストフィルタが直前にピッチを見つけて
  いれば適応寄与を残して固定寄与を捨て、見つけていなければ逆にします。両方を
  足すと、誤っていた方を補強してしまいます。
- 残りは疑似乱数生成器で埋めます。長い消失が無音や固まったブザー音ではなく、
  整形された雑音へ減衰していくようにするためです。

両方ではなく片方を残すという判断が要点です。有声音の最中は周期構造こそ耳が
追っているものであり、それを延長するのは説得力があります。無声音の最中には
延長すべき構造がなく、適応寄与を繰り返せば元々存在しなかった音調が生じます。

## 出力

ポストフィルタ後の信号は最終再構成フィルタ——2次セクション2段の縦続——を通り、
μ-law へ圧伸されます。18バイトのフレーム1個が320バイトの μ-law になります。

帯域内リセットフレームは音声をまったく生みません。`Decoder::decode` が `None`
を返し、デコーダは初期状態に戻ります。
